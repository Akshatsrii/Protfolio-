## 🚀 **About This Project (My Portfolio)**

A **modern, highly interactive personal portfolio website** crafted with **React.js, Vite, and Tailwind CSS**. This portfolio is designed to showcase my technical skills, professional internships, full-stack projects, and hackathon achievements. 

### ✨ **Portfolio UI/UX Features**

| Feature | Description |
|---------|-------------|
| 🖱️ **Magnetic Cursor** | Premium custom trailing cursor with hover magnet effect |
| 🌐 **3D Skill Sphere** | Interactive rotating TagCloud displaying technical skills |
| 🧩 **Bento Grid Design** | Modern bento-style cards for the Achievements & Extracurriculars section |
| 🎬 **Scroll Animations** | Smooth reveal animations using Intersection Observer |
| 📬 **Contact Form** | Functional email contact form powered by Web3Forms |
| 📱 **Responsive UI** | Optimized for desktop, tablet, and mobile devices |
